VGT RHYTHM GUARD 1.2.0 (BETA) — INSTALLATION NOTES

Before you install:

1. If Rhythm Guard is already running, close it first via the tray icon
   (right-click -> Quit) or the Task Manager.

2. Windows SmartScreen may warn about the unsigned setup. Click
   "More info" -> "Run anyway". Only run installers downloaded from the
   official GitHub releases page.

3. This is a BETA build. It is provided for evaluation and personal use.
   Save your work before testing forced breaks or shutdown behavior.

What the setup does:

- Installs per-user to %LOCALAPPDATA%\Programs\VGT Rhythm Guard.
- Requires NO administrator rights and changes no system-wide files.
- Optionally creates a desktop shortcut and enables autostart at sign-in.
- Creates a Start-menu entry and a standard Windows uninstall entry.

You must accept the Terms of Use (Beta Notice, AGPL-3.0, no warranty) on the
next page to continue.

Hints:

- The app runs in the system tray. Open the dashboard from the tray icon or
  the Start-menu shortcut.
- Autostart is intentionally optional and can be changed at any time in
  Settings -> System.
- Emergency exit: hold ESC for 5 seconds and type PAUSE (can be disabled).
